Filtrul universal cu variabile de stare

Un singur circuit, trei ieșiri simultane: trece-sus (FTS), trece-bandă (FTB) și trece-jos (FTJ). Alegi ieșirea din comutator, reglezi f0 și Q și vezi pe viu cum se extrage tonul de măsurare din brum și zgomot. Urmează după L07 (filtrul anti-aliasing).

1. Fișa individuală

Reguli de generare: tonul de măsurare (de exemplu, excitația alternativă a unui senzor) f0 = 400 + 40·N Hz; factorul de calitate cerut Q = 3 + (N mod 4). Semnalul de intrare conține tonul (1 V), brum de 50 Hz (1 V) și o perturbație la 5·f0 (0,5 V). Condensatoarele integratoarelor sunt C = 10 nF.

2. Schema animată

Fire roșii animate = poartă semnal; AO verde = lucrează liniar; AO portocaliu = în saturație; componentă roșie întreruptă = defect. Comutatorul arată ieșirea aleasă.

3. Ecuațiile filtrului

D(s) = s² + s·ω1/Qd + ω1ω2,   ωi = 1/(R·Ci)
HFTS = s²/D  ·  HFTB = ω1s/D  ·  HFTJ = ω1ω2/D
f0 = √(ω1ω2)/(2π) = 1/(2πRC) pentru C1 = C2 = C  ·  Q = Qd·√(ω2/ω1)

Model normalizat: inversările de semn ale AO sunt omise, iar Qd este factorul fixat de rețeaua de amortizare a sumatorului. La f0, câștigul ieșirii FTB este Q. AO ideale cu saturație la ±12 V.

4. Parametri de proiectare

Cerințe: (C1) f0 realizat în ±2 % din cel cerut; (C2) Q în ±5 % din cel cerut; (C3) pe ieșirea FTB, brumul de 50 Hz și perturbația de 5·f0 sunt cu cel puțin 20 dB sub ton.

5. Rezultate și diagrama Bode

Albastru = FTS, verde = FTB, portocaliu = FTJ; ieșirea aleasă este desenată îngroșat. Verticale: 50 Hz, f0 cerut, 5·f0.

6. Osciloscop și jurnal

Gri = intrarea, verde = ieșirea aleasă (fereastră de 20 ms; în modul treaptă, treapta apare la 1 ms). Spotul baleiază ca pe un osciloscop real.
